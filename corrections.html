Corrections

This site is automated, so it can be wrong or late. We want to fix errors fast and in the open.

Report an error

Email contact@breakingnewsdesklive.com. Include the item title, the time shown, and what is wrong. The fastest fix is to also tell the source agency or outlet.

What we do

  • We check the item against its source.
  • If the source data is wrong or changed, the next data run fixes the item. If our reading is wrong, we fix the code.
  • We add an entry below with the date and what changed.
  • If a claim or headline is wrong in the outlet's own words, we cannot change it. We can remove the item or add a note.
  • We remove an item on a valid request from a private person named in it.
